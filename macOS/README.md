# 7-Zip for Mac

基于 7-Zip 26.03 的中文原生 macOS 图形客户端。Swift 6 + SwiftUI，无第三方
Swift 依赖；传统格式由 `7zz`、可恢复 RZ 格式由 `rz` 子进程在本机处理，无网络服务、账户或上传。
这是社区 GUI 工程，不是 Igor Pavlov 发布的官方 macOS GUI。

## 系统要求与启动

- macOS 14 Sonoma 或更新版本。
- 当前构建与交付目标为 Apple Silicon（arm64），不构建 Intel 内核。
- 开发需要支持 Swift 6 的 Xcode 或 Command Line Tools，以及 CMake 3.24+（构建内置恢复引擎）。

已构建的应用位于 `macOS/build/7-Zip for Mac.app`，可双击打开，或将它拖到
“应用程序”文件夹。`macOS/build/7-Zip-for-Mac.zip` 是可携带的应用压缩包。

```sh
cd macOS
Scripts/package_app.sh
Scripts/launch.sh
```

也可以在 Xcode 中打开 `Package.swift` 开发。建议通过打包脚本运行，确保内核、
图标、许可证和 Finder 文件类型关联都包含在应用中。`swift run` 仅在 `macOS/`
工作目录下使用仓库内核，且不会注册完整应用集成。

## 使用方式

1. **打开**：点击“打开压缩包”，使用 `⌘O`，或将归档拖入窗口。Finder 的“打开方式”
   也可选择本应用；不会强行更改系统默认解压软件。
2. **浏览**：左侧“文件浏览”（`⌘1`）提供常用位置、磁盘与卷及按需展开的文件夹树。
   点击树中目录或双击右侧文件夹进入，支持前进、后退、上一级、路径输入、刷新、隐藏文件开关，
   搜索当前文件夹。右侧可切换大图标、中图标、小图标、列表和详细信息，布局自动记忆，
   支持多选及按名称、修改日期、类型、大小排序。普通文件双击用默认应用打开，压缩包双击在同一
   “文件浏览”页面内进入归档，无需切换独立入口。本地目录与归档目录共用前进、后退历史；
   在归档根目录点击“上一级”返回压缩包所在文件夹并选中该压缩包，也可随时通过常用位置切回本地目录。
   选中本地文件后按空格、点击“预览”或右键“快速查看”，可通过系统 Quick Look 预览图片、音频、视频
   及 PDF 等文档；多选文件可在预览窗口中切换，按 Esc 关闭。具体格式与编解码支持取决于 macOS
   和已安装的 Quick Look 扩展；无法预览的类型由系统显示文件信息，可继续用默认应用打开。
   右键可压缩所选项目、新建文件夹、重命名、复制路径、在 Finder 中显示或移到废纸篓；
   压缩包还可解压、测试完整性，RZ 可修复。归档内容使用同样的五种布局，并在侧栏显示归档目录树，
   搜索覆盖整个归档；双击归档内文件会打开整体解压对话框，不直接执行或预览文件内容。
3. **新建**：点击“新建压缩包”或 `⌘N`，添加文件/文件夹，选择 7z、ZIP、TAR 或“可恢复 RZ”、
   压缩等级和输出位置。7z 支持加密文件名；7z/ZIP 支持 AES-256 数据加密。
   AES ZIP 需要支持该加密方式的解压软件。
   **可恢复 RZ** 设置数据卷数量 K（1–100）与恢复卷数量 M（1–K），默认 10+2。
   输出 `.rz` 归档包，包含恰好 K+M 个等大分卷；大小在压缩完成后确定，最后一个条带补零。
   恢复载荷相对补齐后数据的比例为 M/K，索引与卷头另占空间；小归档选过多卷会增加填充开销。
   其余卷完整时，可修复任意 M 个缺失卷（包括数据卷与恢复卷）。局部坏块共同消耗每条带的 M 块预算。
   详情显示数据/恢复卷数量、实际每卷大小和可容忍丢卷数。
   GUI 新建使用 profile 4，旧版 profile 1/2/3 仍可打开、测试、修复和解压。
   压缩按文件帧调度；恢复编码按 K+M 条带宽度、任务量、CPU 和 256 MiB 缓冲预算调度；
   分卷封装按卷数与工作量调度，最多 4 路并行 IO。各阶段依次执行，小任务减少 worker。
   选择“密码”保护会同时加密内容、文件名和属性；未解锁时仍可修复密文。
   “加密方式”默认标准 XChaCha20-Poly1305，也可选择“双层加密（增加 AES）”。
   双层模式额外使用 AES-256-GCM，密钥包装也双层保护；创建和解锁设备必须支持 AES 硬件加速。
   无密码修复只完成密文存储校验，解锁后的完整性测试才认证全部内容。
   RZ 的“保护方式”现在默认“自动生成密钥文件”：创建 `资料.rz` 时同时生成 `资料.rzkey`，
   无需输入密码，默认 AES 双层加密。打开／解压自动匹配同目录密钥，找不到时提示选择。
   归档或密钥改名后仍按归档身份匹配；修复后的归档继续使用原密钥。
   请备份密钥，需要保密时分开存放；密钥丢失后恢复卷也不能解密内容。
   默认勾选“保留文件权限与扩展属性”，保存普通权限、时间、ACL、xattr、Finder 信息和资源叉。
   解压时可取消属性恢复。特殊权限、原所有者或系统限制导致未完整恢复时，会保留内容并显示报告。
   RZ 仍是实验格式，仅本应用支持。单文件属性记录限 64 MiB，公开/私有索引各限 16 MiB。
   Finder 中可用“显示包内容”取出或放回分卷。源内容上限为 64 GiB，另受索引规模限制。
4. **解压**：点击“解压到…”或 `⇧⌘E`，选择父目录和新文件夹名称。归档内容整体解压，
   原目录结构保留；已有目标不会被覆盖。
5. **测试**：点击“测试”或 `⇧⌘T` 验证归档完整性。加密归档会要求密码。
6. **进度与取消**：压缩时底部显示百分比进度条、平均速度、已处理/总文件数、压缩率、
   已处理/总容量及用时；窗口较窄时统计自动换行。7z/ZIP/TAR 的速度、处理容量和实时压缩率
   根据内核百分比估算并标注“约”；压缩率为压缩后大小 ÷ 已处理原始大小（越低越小，可超过 100%）。
   RZ 使用实际处理字节数，压缩率不含恢复卷、索引和属性；生成恢复卷、写入与校验时单独显示阶段。
   扫描或数据尚不可用时显示占位值。操作可取消并清理临时结果。退出应用时若仍在处理，
   会让用户选择继续或取消后退出。
7. **修复 RZ**：打开 `.rz` 归档包或任意 `.rzv` / `.rzr` 分卷，点击“修复归档”，
   选择新的输出位置。修复并验证成功后生成完整副本，原有损坏归档保持原样。
   “测试”会区分完整、仍可恢复和超出恢复能力；补回分卷后可以重新测试。
   加密 RZ 无需密码即可修复存储损坏，查看目录、完整认证与解压仍需密码。

## 内核源码与可复现构建

原仓库为 7-Zip 简体中文资源及网站工程，没有 C/C++ 内核源码。本工程保留用户
提供的 26.03 macOS `7zz`，并补充同版本官方源码压缩包，校验值见
`Vendor/7zip/PROVENANCE.md`。源码来源：
[7-Zip 官方下载页](https://www.7-zip.org/download.html)。

从所附源码构建并打包（无需联网）：

```sh
cd macOS
Scripts/build_engine.sh
SEVENZIP_ENGINE="$PWD/build/engine/7zz" Scripts/package_app.sh
Scripts/build_recovery_engine.sh
SEVENZIP_ENGINE="$PWD/build/engine/7zz" swift test -Xswiftc -warnings-as-errors
```

仅构建当前机器架构以缩短开发时间：

```sh
ARCHES="$(uname -m)" Scripts/package_app.sh debug
```

更换内核后请重新打包并测试。打包脚本自动从 `../recovery/vendor/` 中固定的源码构建 arm64 `rz`，
也可用 `RECOVERY_ENGINE` 指定已构建版本。使用 `swift run` 前先执行 `Scripts/build_recovery_engine.sh`。
脚本不会下载或自动更新任何内核。

## 工程结构

```text
Sources/ArchiveCore/       归档模型、清单解析、进程控制、压缩/解压服务
Sources/SevenZipMac/       SwiftUI 页面、原生文件面板、应用状态和菜单
Tests/ArchiveCoreTests/    真实内核往返、密码、特殊路径、取消与失败测试
Scripts/                  arm64 内核构建、应用打包、图标生成和启动
Resources/Info.plist       应用身份和 Finder 文档类型
Vendor/7zip/              原始内核、对应源码、许可证和校验信息
```

GUI 状态在 MainActor，文件和归档服务在 actor，阻塞式管道读写在专用后台任务。
不经 shell 拼接命令，文件参数使用 `--` 分隔，并关闭输入通配符解析。密码经 stdin
传递，禁止换行；不会保存在偏好设置或进程参数中。当前打开归档的密码仅在内存中保留。

## 数据保护与首版边界

- 压缩、解压都在输出目录下创建权限为 `0700` 的临时目录，成功才移动到最终位置。
  取消或失败清理临时结果，避免留下看似完整的归档。
- 不覆盖已有文件或文件夹；归档中的重复目标名称由内核自动重命名。
- 解压前检查绝对路径、`..` 路径、控制字符和链接。首版拒绝符号链接、硬链接和无法
  可靠解析的清单；含这些内容的归档仍可浏览或测试。不会恢复外部链接。
- 最近 12 个归档的本机路径保存在 UserDefaults，可从首页清除；操作记录只保留本次会话。
- 归档浏览清单限制为 64 MiB；不支持单独提取选中文件、直接修改归档、Finder 快速操作
  扩展、传统格式的分卷创建或自动更新。RZ 支持分卷创建和修复；其他分卷归档可从首卷打开，RAR 仅解压/测试。
- TAR.GZ/TAR.XZ 等嵌套格式按内核的一层归档处理；得到 TAR 后可再次打开并解压。
- 压缩包含系统元数据或权限受限文件时，内核警告会作为未完成处理，不交付可能缺文件的归档。

## 验证与发布

```sh
swift test -Xswiftc -warnings-as-errors
Scripts/package_app.sh
codesign --verify --deep --strict "build/7-Zip for Mac.app"
```

默认使用 ad-hoc 本地签名，适合本机运行。公开分发需使用自己的 Developer ID
（通过 `APP_IDENTITY` 传给打包脚本）签名，然后经 Apple notarization 公证。
当前产物没有 Developer ID 公证，未提交 Mac App Store。最低系统版本仍应在相应实机上验证。

GUI 遵循仓库 LGPL 第 3 版许可证。7-Zip 内核包含 LGPL 2.1 或更新版本、BSD 及 unRAR 附加条件，
具体见应用随附许可证；完整对应源码随应用一同提供。
RZ 使用 Zstd、BLAKE3、Jerasure、GF-Complete 和 libsodium；依赖声明与完整源码一并打包，
详见 [可恢复归档说明](../recovery/README.md)。

本地测试结果与界面截图见 [验证记录](docs/VALIDATION.md)。
