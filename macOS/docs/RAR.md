# RAR GUI 与参数映射

版本：内置 RAR 7.23，macOS ARM64。参考用户指定的
[RAR 参数文档](https://gist.github.com/YenForYang/5953ad8355cf32188aa75c0139cc9261)，
以随附 [7.23 官方手册](../Vendor/rar/rar.txt) 的实际语法为准。
例如当前版本的固实模式关闭参数为 `-s=-`，不提供旧版本 RAR4 创建选项。

## 新建 RAR

新建 → 格式 RAR。普通归档交付 `名称.rar`；启用分卷后交付
`名称.rar-parts/名称.part1.rar` 等，结果链接定位首卷。所有结果验证成功后才移出私有临时目录。

| GUI 设置 | RAR 参数 |
| --- | --- |
| 压缩等级 0–5 | `-m0`…`-m5` |
| 固实压缩 | `-s` / `-s=-` |
| 每卷上限（KiB / MiB / GiB） | `-v<size>b`，GUI 换算为精确字节 |
| 密码 / 同时加密文件名 | `-p` / `-hp`，通过 stdin 提交密码 |
| 恢复记录 1–100% | `-rrNp`，创建时写入每个数据卷 |
| 恢复卷个数 / 比例 | 压缩完成后 `rvN` / `rvNp` |
| 字典 1–1024 MiB / 线程 0–64 | `-mdNm` / `-mtN`（0 为自动） |
| CRC32 / BLAKE2 | `-htc` / `-htb` |
| 快速打开信息 | 默认 / `-qo+` / `-qo-` |
| 锁定归档 | `-k`，在生成 REV 之前完成 |
| 创建后测试 | `t`，失败不交付 |
| 空目录 / 符号链接 / 固实排序 / 属性 | `-ed` / `-ol` 或 `-ol-` / `-ds` / `-ai` |
| 创建时间 / 访问时间 / 归档时间 | `-tsc` / `-tsa` / `-tl` / `-tk` |
| 归档内前缀 / 文件名大小写 | `-ap` / `-cl` / `-cu` |
| 包含 / 排除规则（每行一个） | 多个 `-n` / `-x` |
| 仅存储的扩展名 | `-ms` |
| 最小 / 最大大小 | `-smNb` / `-slNb`，严格大于 / 小于 |
| 修改时间范围 | `-taYYYYMMDDHHmmss` / `-tbYYYYMMDDHHmmss`，本地时间 |
| 多行 UTF-8 注释 | 私有临时文件 + `-z`、`-scf` |

## 已有归档

工具栏“工具”、菜单“归档”或本地文件右键 → RAR 工具。
损坏文件不必先成功列出目录即可进入工具。每次指定一个新的结果文件夹。

| GUI 操作 | 命令 | 行为 |
| --- | --- | --- |
| 正常解压 / 完整性测试 | `x` / `t` | 自动定位首卷；先用 7zz 解析目录并验证路径 |
| 恢复记录修复 | `r` | 在副本上修复，成功测试后交付；分卷逐卷修复并恢复原卷名 |
| REV 重建 | `rc` | 可选任意现存数据卷或 REV，重建首卷缺失等情况 |
| 添加恢复记录 / 生成 REV | `rrNp` / `rvN[p]` | 生成新的受保护副本 |
| 添加 / 添加及更新 / 仅更新 | `a` / `u` / `f` | 单文件归档，按相对路径匹配 |
| 删除 / 重命名 | `d` / `rn` | 删除支持匹配规则；重命名一个确切条目并拒绝重名目标 |
| 注释 / 导出注释 / 锁定 | `c` / `cw` / `k` | 原归档保持不变 |
| 平铺解压 | `e -or` | 同名文件自动改名 |
| 文件名清单 / 技术信息 | `lb -v` / `lta -v` | 输出 UTF-8 文本 |
| 自解压转换 / 移除模块 | `s<module>` / `s-` | 生成的 ARM64 macOS 可执行文件不会被自动运行 |

恢复记录修复可能改写卷头，因此分卷修复结果不保留旧 REV；可再对修复结果生成新的 REV。
REV 重建则保留整组卷，适用于缺卷恢复。完整性测试/解压使用私有目录中的数据卷引用，
不让 RAR 自动在用户源目录中重建或重命名卷；需要恢复时请显式选择工具中的修复操作。

## 自动管理的参数与边界

- `-cfg-` 隔离用户 RAR 配置；`-@` 与 `--` 隔离文件清单和选项。
  无密码时省略加密开关并关闭 stdin，不使用旧版 `-p-`：RAR 7.23 会将其视为密码 `-`。
  不拼接 shell 命令，不把密码放入 argv、偏好设置或记录。
- `-y`、输出目录、临时目录、字符集、进度输出等由应用管理；不提供自由拼接命令行框。
- 只交付到新位置；不提供覆盖原归档、直接删源/擦除（`m`、`-df`、`-dw`）、绝对路径恢复（`-ep3`）
  或 Windows 专用的 NTFS、优先级、关机等参数。也不提供 stdin 管道、日志重定向等终端操作。
- 本 GUI 覆盖上述工作流和参数，并非手册中每一个底层开关的逐项包装。
  内容搜索、历史文件版本、不同分卷分别指定容量及高级 `-mc` 算法参数目前未开放。
- 分卷不可原地更新，恢复记录须在创建时加入；REV 至少需要两个数据卷，个数须少于数据卷数。
  极小输入无法产生足够数据卷时会报错并清理全部临时文件。
- 拒绝直接选择带 `*` / `?` 的源路径以免 RAR 扩大匹配；可选择其不含通配符的父目录打包。
  RAR 归档及输出路径也不能含这些通配符或控制字符。
- 符号链接默认跳过；明确选择保存链接后，可以浏览/测试，但安全解压仍拒绝含链接归档。
- 密码最多 127 个 Unicode 标量，避免 RAR 静默截断。加密修复需要密码完成最终内容验证。
- 创建采用当前 RAR5 格式。大字典与新版特性要求接收方使用兼容的新版本解压软件。

## 打包与许可

`Scripts/package_app.sh` 将用户提供的 `rar`、`unrar` 和 `default.sfx`
放入应用 `Contents/MacOS`，`rarfiles.lst`、许可及手册放入 `Contents/Resources/RAR`，逐个签名后签名应用。
生成的包无需 Homebrew 或 PATH 配置。`rarreg.key` 不在仓库、源码包或应用中。
内核自动使用用户主目录中的注册文件；该 GUI 本身不修改注册状态。

此内置构建用于本地使用。RAR 为专有软件，其捆绑再分发受到附带许可约束；
公开分发前需要厂商许可。见 [来源与许可说明](../Vendor/rar/PROVENANCE.md)。
