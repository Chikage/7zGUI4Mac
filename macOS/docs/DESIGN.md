# 界面与产品范围

目标用户：希望在 Mac 上使用 7-Zip、无需理解命令行的日常文件用户。
核心循环：打开或拖入 → 查看/选择输出 → 压缩或解压 → 在 Finder 中取得结果。
验收：真实文件往返一致，错误/密码/取消可处理，能以独立 `.app` 启动。

采用原生 SwiftUI NavigationSplitView，左侧工作台、归档浏览、操作记录；右侧工作区。
工具栏承载打开、新建、测试与解压，页面提供同等可访问的按钮和键盘快捷键。
中文为首版界面语言，使用系统字体与语义字阶，SF Symbols 表达文件/动作。
以系统蓝为主要操作色，主次文字、背景、边框采用系统语义颜色，适应浅色与深色。
无装饰性循环动画，不依靠动画传递状态；进度使用原生控件。

ui-ux-pro-max 查询结果中 File Manager & Transfer 推荐的简洁布局、文件类型色彩提示
适用于本应用。初始设计系统返回的网站营销结构不适用于桌面工具，因此使用上述
原生多栏界面；不采用网站 Hero/CTA 布局与外部网页字体。

最小窗口 850 × 600，可调整侧栏宽度。表格虚拟化显示，文件名截断时可通过悬停
查看完整路径；所有图标按钮具有文字辅助标签；拖放有按钮替代，操作不依赖颜色识别。
