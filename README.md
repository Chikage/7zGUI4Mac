# 7-Zip Chinese Simplified Repository

## Structures

- `website/` Astro-based static site
- `macOS/` Native SwiftUI 7-Zip GUI for macOS 14+ on Apple Silicon,
  archive browsing, compression, extraction, encryption, and integrity testing.
  See [macOS build and usage instructions](macOS/README.md).
- `recovery/` Experimental recoverable archive CLI using Zstd, BLAKE3 and
  Reed–Solomon K+M equal-sized data and recovery volumes. See [build, usage and limits](recovery/README.md).
